# Simplicitor v2.5.1 release notes

## What's fixed

- The Simplicitor logo now appears in the header of the installed and portable app.
- The header matches the approved design: icons on Create new and Edit document, the italic "Powered by your local LLM" line, and a clearer outline on the selected mode.

Your documents and the AI processing stay on your computer; nothing is uploaded.

## Before you start

- You need Windows and Ollama running locally with a downloaded model. We recommend a model with at least 8 billion parameters (8B+) and a GPU with 8 GB of video memory.
- English documents are supported. Pull information into Excel reads Word documents and PDFs with selectable text, not scanned PDFs. Check reading problems and highlighted values before using the table. AI can make mistakes; review proposed Word changes before saving.
- If you have Simplicitor 2.1.0 through 2.5.0, the new installer replaces it; your settings and documents stay. If you installed 2.0.0 with Simplicitor-setup.exe, uninstall it from Settings > Apps first.
- The installer is unsigned. Windows may show an unknown-publisher or security warning.

## Downloads

- `Simplicitor-2.5.1.msi`: installer.
- `Simplicitor-portable.zip`: unpack and run without installing.
- `SHA256SUMS.json`: file checksums for verifying the downloads.
