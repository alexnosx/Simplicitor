# Simplicitor v2.0.0 release notes (draft)

Unreleased. This repository draft is not a tag, GitHub release, or publication.

## What's new

Turn information from Word (.docx) files and PDFs with selectable text into an Excel (.xlsx) file using local AI. Choose the columns you need, review the results, and save your spreadsheet. The Evidence sheet records the source quote and location for each extracted value.

The legacy Edit feature has been removed from the app. Existing document creation from prompts and PowerPoint templates remains available.

## Before you start

- You need Windows and Ollama running locally with a downloaded model. We recommend a model with at least 8 billion parameters (8B+) and a GPU with 8 GB of video memory.
- This release supports English documents. Scanned PDFs are not supported.
- If a file is too large for one AI request, Simplicitor processes it in sections and highlights every extracted value for your review. Check the highlighted results before saving.
- The installer is unsigned. Windows may show an unknown-publisher or security warning.

## Downloads

- `Simplicitor-setup.exe`: installer.
- `Simplicitor-portable.zip`: unpack and run without installing.
- `SHA256SUMS.json`: file checksums for verifying the downloads.
