# Simplicitor v2.3.2 release notes

## What's fixed

- Simplicitor could occasionally stop responding when a task finished: after opening a document to edit, after pulling information into Excel, or after creating a file. Background tasks now hand their cleanup back to the main window, so this can no longer happen that way.

Your documents and the AI processing stay on your computer; nothing is uploaded.

## Before you start

- You need Windows and Ollama running locally with a downloaded model. We recommend a model with at least 8 billion parameters (8B+) and a GPU with 8 GB of video memory.
- If you have Simplicitor 2.1.0, 2.2.0, 2.3.0 or 2.3.1, the new installer replaces it; your settings and documents stay. If you installed 2.0.0 with Simplicitor-setup.exe, uninstall it from Settings > Apps first.
- The installer is unsigned. Windows may show an unknown-publisher or security warning.

## Downloads

- `Simplicitor-2.3.2.msi`: installer.
- `Simplicitor-portable.zip`: unpack and run without installing.
- `SHA256SUMS.json`: file checksums for verifying the downloads.
