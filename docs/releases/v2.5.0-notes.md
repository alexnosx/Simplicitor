# Simplicitor v2.5.0 release notes

## What's new

- A refreshed blue Windows workspace with clearer Word, PDF, Excel and PowerPoint choices, readable controls and consistent colours for choices, progress and review.
- Source filenames, reading states and Remove fit on one line. Long save-folder paths stay on one line, with the full path available when you hover. Smaller windows can scroll to the controls.
- Word review now shows removed or replaced text in red and crossed out in Before, alongside green changes in After. A notice calls out original paragraphs removed or merged, so you can check what disappeared before accepting the change.

Your documents and the AI processing stay on your computer; nothing is uploaded.

## Before you start

- You need Windows and Ollama running locally with a downloaded model. We recommend a model with at least 8 billion parameters (8B+) and a GPU with 8 GB of video memory.
- English documents are supported. Pull information into Excel reads Word documents and PDFs with selectable text, not scanned PDFs. Check reading problems and highlighted values before using the table. AI can make mistakes; review proposed Word changes before saving.
- If you have Simplicitor 2.1.0 through 2.3.2, the new installer replaces it; your settings and documents stay. If you installed 2.0.0 with Simplicitor-setup.exe, uninstall it from Settings > Apps first.
- The installer is unsigned. Windows may show an unknown-publisher or security warning.

## Downloads

- `Simplicitor-2.5.0.msi`: installer.
- `Simplicitor-portable.zip`: unpack and run without installing.
- `SHA256SUMS.json`: file checksums for verifying the downloads.
