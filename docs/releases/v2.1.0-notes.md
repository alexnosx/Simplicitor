# Simplicitor v2.1.0 release notes

## What's new

- **PDF files.** Create a PDF from a description, the same way as a Word file.
- **A simpler screen.** Simplicitor now has two modes: Create new and Edit document. Create new takes a description, a file type, and optional source files. With source files, it pulls the information you ask for into an Excel table.
- **A standard Windows installer.** Simplicitor now installs from a .msi file. Uninstall it any time from Settings > Apps; your settings and documents stay.

Your documents and the AI processing stay on your computer; nothing is uploaded.

## Before you start

- You need Windows and Ollama running locally with a downloaded model. We recommend a model with at least 8 billion parameters (8B+) and a GPU with 8 GB of video memory.
- This release supports English documents. Scanned PDFs are not supported as source files.
- If a source file is too large for one AI request, Simplicitor processes it in sections and highlights every extracted value for your review. Check the highlighted results before saving.
- If you installed Simplicitor 2.0.0 with Simplicitor-setup.exe, uninstall it from Settings > Apps first. The new installer will tell you if it is still there. Your settings and documents are kept.
- The installer is unsigned. Windows may show an unknown-publisher or security warning.
- Edit document explains that editing is coming in a later version.

## Downloads

- `Simplicitor-2.1.0.msi`: installer.
- `Simplicitor-portable.zip`: unpack and run without installing.
- `SHA256SUMS.json`: file checksums for verifying the downloads.
