# Simplicitor v2.3.0 release notes

## What's new

- **Edit your Word documents.** Open a .docx, select the paragraphs you want to change, describe the change, and review the result before saving. Simplicitor saves a new file; it suggests the original's folder and you choose where. The original is never changed.
- **Only your selection changes.** Everything outside the selected paragraphs stays exactly as it was, byte for byte. Tables, headers and footers are shown read-only. Paragraphs with links, fields, pictures, comments or tracked changes are shown read-only with the reason they cannot be edited yet.
- **See what changed.** The review shows the selected part before and after, with the changed words highlighted.

Your documents and the AI processing stay on your computer; nothing is uploaded.

## Good to know

- Each saved file holds one change. To make another, open the new file.
- If the document has Track Changes turned on, the change is saved without revision marks.
- Local AI models sometimes return the text unchanged, especially when asked to shorten it. Use Try again or reword the description.

## Before you start

- You need Windows and Ollama running locally with a downloaded model. We recommend a model with at least 8 billion parameters (8B+) and a GPU with 8 GB of video memory.
- Editing supports Word documents (.docx). Password-protected, digitally signed and Word-protected documents cannot be edited.
- If you have Simplicitor 2.1.0 or 2.2.0, the new installer replaces it; your settings and documents stay. If you installed 2.0.0 with Simplicitor-setup.exe, uninstall it from Settings > Apps first.
- The installer is unsigned. Windows may show an unknown-publisher or security warning.

## Downloads

- `Simplicitor-2.3.0.msi`: installer.
- `Simplicitor-portable.zip`: unpack and run without installing.
- `SHA256SUMS.json`: file checksums for verifying the downloads.
