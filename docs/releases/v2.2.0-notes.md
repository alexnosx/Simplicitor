# Simplicitor v2.2.0 release notes

## What's new

- **A clearer Create screen.** Choose what you want first: write a new document, or pull information from your documents into an Excel table. Text is larger, and every box says what it is for.
- **Built-in templates only.** Uploading your own PowerPoint file as a template is removed; the built-in templates stay.
- **Clear reading problems.** When part of a Word file cannot be read, Simplicitor names it, for example text boxes or tracked changes, and asks you to check these problems before you use the table.
- **The version is shown** in the window title, the top bar and Settings.

Your documents and the AI processing stay on your computer; nothing is uploaded.

## Fixed

- Progress messages such as "Suggesting columns from the first source..." no longer stay on screen after the step has finished.
- With source files added, the request box now hints at what to pull from them.
- The message about choosing a model now points to Settings.
- Text in tracked moves in Word files is now named as not read.

## Before you start

- You need Windows and Ollama running locally with a downloaded model. We recommend a model with at least 8 billion parameters (8B+) and a GPU with 8 GB of video memory.
- This release supports English documents. Scanned PDFs are not supported as source files.
- If a source file is too large for one AI request, Simplicitor processes it in sections and highlights every extracted value for your review.
- If you have Simplicitor 2.1.0, the new installer replaces it; your settings and documents stay. If you installed 2.0.0 with Simplicitor-setup.exe, uninstall it from Settings > Apps first.
- The installer is unsigned. Windows may show an unknown-publisher or security warning.

## Downloads

- `Simplicitor-2.2.0.msi`: installer.
- `Simplicitor-portable.zip`: unpack and run without installing.
- `SHA256SUMS.json`: file checksums for verifying the downloads.
