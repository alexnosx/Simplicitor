### Task 1: Edit drop area outline visible on every edge

**Files:**
- Modify: `simplicitor/app/widgets/edit_screen.py` (imports, a module constant, a new `DropArea` class above `EditScreen`, the drop zone lines in `_build_pages`)
- Test: `tests/test_edit_screen.py` (append)

**Interfaces:**
- Produces: `DropArea(QLabel)` in `app.widgets.edit_screen`; `EditScreen._drop_zone` is now a `DropArea`, with the same text and `isVisible()` behavior the existing tests use.

Cause: the outline was a style-sheet `1px dashed #9CA8B7` border. Qt draws it as sparse light dots; at 125% scaling the top edge measured 0.28 dark pixels per position against 0.4 to 0.52 for the others, and on Alex's display it vanished. A painted 1.5 px dash in the mockup's darker `#8996A9`, inset by half its width, measured 1.56 to 2.56 on every edge at 100%, 125% and 150%.

- [ ] **Step 1: Write the failing test.** Append to `tests/test_edit_screen.py`:

```python


@pytest.mark.parametrize("ratio", [1.0, 1.25, 1.5])
def test_drop_zone_outline_is_visible_on_all_four_edges(qtbot, ratio):
    from PySide6.QtGui import QColor, QImage
    from app.widgets.edit_screen import EditScreen
    page = EditScreen()
    qtbot.addWidget(page)
    page.resize(1240, 700)
    page.show()
    zone = page._drop_zone
    qtbot.waitUntil(zone.isVisible)
    # Render as a display at this scale would; Alex's 125% display lost the top edge.
    image = QImage(round(zone.width() * ratio), round(zone.height() * ratio), QImage.Format.Format_ARGB32)
    image.setDevicePixelRatio(ratio)
    image.fill(QColor("white"))
    zone.render(image, QPoint())
    w, h, band = image.width(), image.height(), round(3 * ratio)

    def line_weight(points):
        """Dark pixels per position along an edge, counted inside the outer band."""
        points = list(points)
        dark = sum(image.pixelColor(x, y).lightness() < 215 for x, y in points)
        return dark / (len(points) / band)

    xs, ys = range(20, w - 20), range(20, h - 20)
    edges = {
        "top": line_weight((x, y) for x in xs for y in range(band)),
        "bottom": line_weight((x, y) for x in xs for y in range(h - band, h)),
        "left": line_weight((x, y) for y in ys for x in range(band)),
        "right": line_weight((x, y) for y in ys for x in range(w - band, w)),
    }
    assert all(weight >= 1.0 for weight in edges.values()), edges
```

```python
class DropArea(QLabel):
    """Drop target whose dashed outline is painted, so all four edges stay visible at any display scale."""

    def paintEvent(self, event) -> None:
        super().paintEvent(event)
        painter = QPainter(self)
        painter.setRenderHint(QPainter.RenderHint.Antialiasing)
        painter.setPen(QPen(QColor(DROP_BORDER_COLOR), 1.5, Qt.PenStyle.DashLine))
        # Inset by the pen's half-width so no edge is clipped at fractional scales.
        painter.drawRoundedRect(QRectF(self.rect()).adjusted(1, 1, -1, -1), 4, 4)
        painter.end()


```
