# Simplicitor 2.2.0 Implementation Plan, with the 2.3.0 roadmap

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship 2.2.0 with the fixes and clarity changes from Alex's 2.1.0 testing, PowerPoint templates made from any uploaded deck, and a redesigned Create new screen; then build Edit for Word files as 2.3.0.

**Architecture:** Part A fixes behavior and text that needs no new design (stale progress lines, wrong hints, one version number for the app, the build and the installer qualification, named reading problems). Part B adds two engine modules: `deck_style.py` reads the effective look of any deck and decides whether its slides override their layouts, and `styled_template.py` turns a captured look into a normal fillable template built from the bundled default template. One shared step, `prepare_template`, chooses between the deck's own layouts and its captured look; the test run with Alex's decks and the app's import both use it, so the gate judges what ships. Part C is a mockup round (Claude with Alex); Part D, the Qt redesign of Create new, is specified in a later revision after the mockup is approved. Part E prepares and releases 2.2.0.

**Tech Stack:** Python 3.12 locally (`.venv`), Python 3.11 on GitHub Actions; PySide6 6.11.2; python-pptx 1.0.x with lxml; Pillow (already installed and bundled as a python-pptx dependency); python-docx; pytest and pytest-qt.

**Spec:** the [Decisions](#decisions-this-plan-implements-alex-2026-10-12) section below, from Alex's 2.1.0 test feedback (his local file `Simplicitor\V2.1\bugs and features.docx`, eight items with screenshots) and his answers on 2026-10-12.

**Status:** Revision 4, 2026-10-12, after the B3 gate. Gate B3 ended in a drop (see [B3 gate result](#b3-gate-result-2026-10-12)): revision 4 writes Task B5 as tested code and marks Task B4 as not executed. Parts A and B1 to B3 are implemented on `main` as written in revision 3, which followed the [Codex review of revision 1](../../reviews/2026-10-12-release-2.2.0-codex.md), the [Codex review of revision 2](../../reviews/2026-10-12-release-2.2.0-codex-revision-2.md) and the [Codex review of revision 3](../../reviews/2026-10-12-release-2.2.0-codex-revision-3.md); their text below is unchanged. ## Part B: Templates from any deck

Today an upload keeps only the deck's slide master and layouts, deletes every slide (`breakdown.strip_to_template`) and fills the layouts' placeholders (`render_pptx.render`). The look survives only when it lives in the master and layouts:

| Kind of deck | Where its look lives | Today | After Part B |
|---|---|---|---|
| Company template made in PowerPoint | Master and layouts, with placeholders; slides follow them | Works | Unchanged: its own layouts |
| Deck built slide by slide in PowerPoint | Each slide: its own backgrounds, fonts, colors or logo; layouts are the plain defaults | Accepted, but the result looks plain | Look captured from the slides |
| Canva and AI-tool exports, typically | Each slide, as free text boxes and pictures; no content placeholders | Rejected ("This deck can't be used as a template") | Look captured from the slides |

**The route.** A deck keeps its own layouts when they can be filled and its slides follow them: fewer than half the slides set their own background, no small picture repeats in the same place on half the slides, and less than half of the title text and less than half of the body text has a font or color its layout does not give. Otherwise the look is captured. Each slide is compared with what its own layout and master give, so formatting or a background the slides only inherit does not count. A company template whose slides follow their master keeps its designed layouts; a hand-built deck on the plain white theme with its own fonts and logo is captured.

**Captured.** Slide size; theme colors; the effective fonts, sizes, colors and boldness of titles and body text (the run, the paragraph defaults, the shape's list style, the layout and master placeholders, the master's text styles, then the theme; within each list style a level's properties, then its default paragraph), each slide read against its own master, theme and color map, with PowerPoint's lighter and darker color variants; the title slide's effective background and the most common effective background of the other slides (a color or a picture: the slide's own, else its layout's, else its master's); the logo. Known limits: a theme background style that is a gradient or texture is taken as its base color, and other color adjustments (tint, shade, saturation, transparency) are ignored. Not copied: slide compositions, icons, charts, SmartArt, animations. The captured look is applied to the bundled `simplicitor/templates/pptx_default.pptx` (byte-identical to python-pptx's default template, bundled because the package's own copy is unreachable in the packaged app), whose layouts have title and content placeholders. A fixed manifest names four slide types, so the AI prompt, validation and rendering are unchanged. A picture that cannot be read or fully decoded is skipped and the rest of the look is kept.

```python
            for shape, font in ((slide.shapes.title, "Georgia"), (slide.placeholders[1], "Verdana")):
                shape.text_frame.paragraphs[0].runs[0].font.name = font
    prs.save(str(path))

def corrupt_png() -> bytes:
    """A PNG whose header and checksums are valid but whose pixel data cannot be decoded."""
    buffer = io.BytesIO()
    Image.new("RGB", (16, 16), (9, 9, 9)).save(buffer, "PNG")
    data = buffer.getvalue()
    start = data.index(b"IDAT") - 4
    length = struct.unpack(">I", data[start:start + 4])[0]
    payload = b"\x78\x9c" + b"\xff" * 10
    chunk = (struct.pack(">I", len(payload)) + b"IDAT" + payload
             + struct.pack(">I", zlib.crc32(b"IDAT" + payload)))
    return data[:start] + chunk + data[start + 12 + length:]


def webp() -> bytes:
    """A real picture in a format python-pptx does not support."""
    buffer = io.BytesIO()
    Image.new("RGB", (8, 8), (9, 9, 9)).save(buffer, "WEBP")
    return buffer.getvalue()


def damage_pictures(path: Path, data: bytes) -> Path:
    """Replace the bytes of every embedded picture; the deck itself stays readable."""
    original = path.read_bytes()
    with zipfile.ZipFile(io.BytesIO(original)) as source, zipfile.ZipFile(path, "w") as target:
        for item in source.infolist():
            content = source.read(item.filename)
            target.writestr(item, data if item.filename.startswith("ppt/media/") else content)
    return path
```

```python
# simplicitor/templates_engine/deck_style.py
"""Read the look of any .pptx deck, best effort and read-only.

Every slide is read against its own layout, master and theme. Text styles follow
PowerPoint's inheritance: the run, the paragraph's defaults, the shape's own list
style, then (for placeholders) the layout and master placeholders and the master's
title, body or other style, then the theme. Within each list style a level's
properties come before the style's default paragraph. Colors go through the
slide's color map and PowerPoint's lighter and darker variants. A slide's
background is its own, else its layout's, else its master's.
"""
import colorsys
import io
from collections import Counter
from dataclasses import dataclass
from pathlib import Path

from lxml import etree
from PIL import Image
from pptx.enum.shapes import MSO_SHAPE_TYPE, PP_PLACEHOLDER
from pptx.opc.constants import RELATIONSHIP_TYPE as RT
from pptx.oxml.ns import qn

_STANDARD_MAP = {"bg1": "lt1", "tx1": "dk1", "bg2": "lt2", "tx2": "dk2"}
_TITLES = {PP_PLACEHOLDER.TITLE, PP_PLACEHOLDER.CENTER_TITLE, PP_PLACEHOLDER.VERTICAL_TITLE}
_OTHERS = {PP_PLACEHOLDER.DATE, PP_PLACEHOLDER.FOOTER, PP_PLACEHOLDER.SLIDE_NUMBER,
           PP_PLACEHOLDER.HEADER}
# Linked, missing, damaged, unsupported or oversized images are skipped, never fatal.
_IMAGE_ERRORS = (AttributeError, KeyError, ValueError, OSError, Image.DecompressionBombError)


@dataclass(frozen=True)
class TextStyle:
    font: str | None = None
    size_pt: float | None = None
    color: str | None = None  # "RRGGBB"
    bold: bool | None = None


@dataclass(frozen=True)
class Fill:
    color: str | None = None  # "RRGGBB"
    image: bytes | None = None
    image_ext: str = ""


# A background style giving the theme's light color, which a new template shows anyway.
_PLAIN = Fill()


@dataclass(frozen=True)
class Logo:
    image: bytes
    image_ext: str
    left: float  # fractions of the slide width and height
    top: float
    width: float
    height: float


@dataclass(frozen=True)
class DeckStyle:
    slide_width: int
    slide_height: int
    color_scheme: bytes | None  # the deck theme's <a:clrScheme> element
    title: TextStyle
    body: TextStyle
    title_background: Fill | None  # None: the slide follows the template's master
    background: Fill | None
    logo: Logo | None


@dataclass(frozen=True)
class _Theme:
    slots: dict  # color slot (dk1, lt1, accent1...) to "RRGGBB"
    scheme: bytes | None
    major: str | None
    minor: str | None


@dataclass(frozen=True)
class _Run:
    style: TextStyle  # the effective style
    weight: int  # characters
    on_slide: bool  # its font or color is set on the slide and differs from its layout's


@dataclass(frozen=True)
class _Deck:
    width: int
    height: int
    colors: dict  # the colors of the master most slides use
    theme: _Theme  # that master's theme
    title_runs: list
    body_runs: list
    fills: list  # each slide's own background, or None
    backgrounds: list  # each slide's effective background; None is the plain default
    logo: Logo | None


def _open(path: str | Path):
    from templates_engine.breakdown import _open_presentation
    return _open_presentation(Path(path))


def _theme(master) -> _Theme:
    """A master's theme: colors by slot name, the raw color scheme, the two fonts."""
    part = master.part.part_related_by(RT.THEME)
    elements = etree.fromstring(part.blob).find(qn("a:themeElements"))
    slots: dict[str, str] = {}
    scheme = elements.find(qn("a:clrScheme")) if elements is not None else None
    if scheme is not None:
        for slot in scheme:
            if len(slot):
                value = slot[0].get("lastClr") or slot[0].get("val")
                if value:
                    slots[etree.QName(slot).localname] = value.upper()
    fonts = elements.find(qn("a:fontScheme")) if elements is not None else None

    def typeface(kind: str) -> str | None:
        latin = fonts.find(f"{qn(kind)}/{qn('a:latin')}") if fonts is not None else None
        return (latin.get("typeface") or None) if latin is not None else None

    raw = etree.tostring(scheme) if scheme is not None else None
    return _Theme(slots, raw, typeface("a:majorFont"), typeface("a:minorFont"))


def _color_map(*owners):
    """The color map in force: the first override among *owners*, else the last one's map."""
    for owner in owners[:-1]:
        override = owner._element.find(f"{qn('p:clrMapOvr')}/{qn('a:overrideClrMapping')}")
        if override is not None:
            return override
    return owners[-1]._element.find(qn("p:clrMap"))


def _colors(theme: _Theme, mapping) -> dict[str, str]:
    """The theme's slots plus bg1, tx1, bg2, tx2 and any other name the color map gives."""
    names = {**_STANDARD_MAP, **(dict(mapping.attrib) if mapping is not None else {})}
    return {**theme.slots,
            **{name: theme.slots[slot] for name, slot in names.items() if slot in theme.slots}}


def _fraction(color, tag: str) -> float | None:
    element = color.find(qn(tag))
    value = element.get("val", "") if element is not None else ""
    return int(value) / 100000 if value.isdigit() else None


def _variant(value: str, color) -> str:
    """Apply PowerPoint's lighter and darker variants (lumMod, lumOff) to "RRGGBB"."""
    scale, shift = _fraction(color, "a:lumMod"), _fraction(color, "a:lumOff")
    if scale is None and shift is None:
        return value
    hue, light, saturation = colorsys.rgb_to_hls(
        *(int(value[i:i + 2], 16) / 255 for i in (0, 2, 4)))
    light = min(max(light * (1 if scale is None else scale) + (shift or 0), 0), 1)
    return "".join(f"{round(c * 255):02X}" for c in colorsys.hls_to_rgb(hue, light, saturation))


def _color(element, colors: dict[str, str]) -> str | None:
    if element is None:
        return None
    srgb = element.find(qn("a:srgbClr"))
    if srgb is not None and srgb.get("val"):
        return _variant(srgb.get("val").upper(), srgb)
    scheme = element.find(qn("a:schemeClr"))
    if scheme is not None:
        value = colors.get(scheme.get("val", ""))
        return _variant(value, scheme) if value else None
    system = element.find(qn("a:sysClr"))
    if system is not None and system.get("lastClr"):
        return _variant(system.get("lastClr").upper(), system)
    return None


def _first(*styles: TextStyle) -> TextStyle:
    """Each property from the first style that sets it."""
    def pick(name: str):
        return next((getattr(s, name) for s in styles if getattr(s, name) is not None), None)
    return TextStyle(pick("font"), pick("size_pt"), pick("color"), pick("bold"))


def _props(element, colors: dict[str, str], major: str | None, minor: str | None) -> TextStyle:
    """What one a:rPr or a:defRPr element sets; unset properties are None."""
    if element is None:
        return TextStyle()
    latin = element.find(qn("a:latin"))
    font = latin.get("typeface") if latin is not None else None
    font = {"+mj-lt": major, "+mn-lt": minor}.get(font, font) or None
    size = element.get("sz")
    size = int(size) / 100 if size and size.isdigit() else None
    bold = {"1": True, "true": True, "0": False, "false": False}.get(element.get("b"))
    return TextStyle(font, size, _color(element.find(qn("a:solidFill")), colors), bold)


def _level(styles, level: int, colors, major, minor) -> TextStyle:
    """One paragraph level of a list or text style, over that style's default paragraph."""
    if styles is None:
        return TextStyle()
    return _first(*(_props(styles.find(f"{qn(tag)}/{qn('a:defRPr')}"), colors, major, minor)
                    for tag in (f"a:lvl{level}pPr", "a:defPPr")))


def _list_style(shape):
    return shape._element.find(f"{qn('p:txBody')}/{qn('a:lstStyle')}")


def _inherited_styles(shape, master, presentation) -> list:
    """Style elements the shape's text inherits, nearest first, excluding the shape itself."""
    if not shape.is_placeholder:
        return [presentation.find(qn("p:defaultTextStyle"))]
    sources, base = [], shape
    for _ in range(2):  # the layout placeholder, then the master placeholder
        try:
            base = base._base_placeholder
        except (AttributeError, KeyError):
            base = None
        if base is None:
            break
        sources.append(_list_style(base))
    kind = shape.placeholder_format.type
    name = ("p:titleStyle" if kind in _TITLES
            else "p:otherStyle" if kind in _OTHERS else "p:bodyStyle")
    sources.append(master._element.find(f"{qn('p:txStyles')}/{qn(name)}"))
    return sources


def _runs(shape, master, presentation, colors, major, minor) -> list[_Run]:
    """The effective style of every non-empty run, and whether the slide overrides it."""
    title = shape.is_placeholder and shape.placeholder_format.type in _TITLES
    theme = TextStyle(major if title else minor, None, colors.get("tx1"), None)
    sources = _inherited_styles(shape, master, presentation)
    own_styles = _list_style(shape)
    result = []
    for paragraph in shape.text_frame.paragraphs:
        level = min(paragraph.level + 1, 9)
        inherited = _first(*(_level(source, level, colors, major, minor) for source in sources),
                           theme)
        defaults = _first(
            _props(paragraph._p.find(f"{qn('a:pPr')}/{qn('a:defRPr')}"), colors, major, minor),
            _level(own_styles, level, colors, major, minor))
        for run in paragraph.runs:
            text = run.text.strip()
            if not text:
                continue
            own = _first(_props(run._r.find(qn("a:rPr")), colors, major, minor), defaults)
            on_slide = own.font not in (None, inherited.font) or own.color not in (
                None, inherited.color)
            result.append(_Run(_first(own, inherited), len(text), on_slide))
    return result


def _iter_shapes(shapes):
    for shape in shapes:
        if shape.shape_type == MSO_SHAPE_TYPE.GROUP:
            yield from _iter_shapes(shape.shapes)
        else:
            yield shape


def _title_shape(shapes: list, height: int):
    """The title placeholder, else the shape near the top with the largest text."""
    for shape, _ in shapes:
        if shape.is_placeholder and shape.placeholder_format.type in _TITLES:
            return shape
    top = [(shape, runs) for shape, runs in shapes
           if shape.top is not None and shape.top < height * 0.4]
    if not top:
        return None
    return max(top, key=lambda item: (max((r.style.size_pt or 0 for r in item[1]), default=0),
                                      -item[0].top))[0]


def _weighted_median(values: list[tuple[float, int]]) -> float | None:
    values = sorted(values)
    total = sum(weight for _, weight in values)
    running = 0
    for value, weight in values:
        running += weight
        if running * 2 >= total:
            return value
    return None


def _dominant(runs: list[_Run], font: str | None, color: str | None) -> TextStyle:
    """The most used font, color and boldness, and the median size, weighted by characters."""
    def most(attribute: str):
        counts: Counter = Counter()
        for run in runs:
            value = getattr(run.style, attribute)
            if value is not None:
                counts[value] += run.weight
        return counts.most_common(1)[0][0] if counts else None

    size = _weighted_median([(r.style.size_pt, r.weight) for r in runs if r.style.size_pt])
    return TextStyle(most("font") or font, size, most("color") or color, most("bold"))


def _readable(blob: bytes) -> bool:
    """True when the whole image decodes; opening an image reads only its header."""
    try:
        with Image.open(io.BytesIO(blob)) as image:
            image.load()
    except _IMAGE_ERRORS:
        return False
    return True


def _picture(shape):
    """(blob, extension, SHA-1) of a picture's embedded image, or None when unusable."""
    try:
        image = shape.image
        found = (image.blob, image.ext, image.sha1)  # ext reads the image header
    except _IMAGE_ERRORS:
        return None
    return found if _readable(found[0]) else None


def _fill(parent, part, colors: dict[str, str]) -> Fill | None:
    """Read a solid, gradient (first stop) or picture fill under *parent*."""
    if parent is None:
        return None
    for tag in ("a:solidFill", "a:gradFill"):
        element = parent.find(qn(tag))
        if element is not None:
            if tag == "a:gradFill":
                element = element.find(f"{qn('a:gsLst')}/{qn('a:gs')}")
            color = _color(element, colors)
            return Fill(color=color) if color else None
    blip = parent.find(f"{qn('a:blipFill')}/{qn('a:blip')}")
    if blip is not None and blip.get(qn("r:embed")):
        try:
            image = part.related_part(blip.get(qn("r:embed")))
            blob, ext = image.blob, image.ext
        except _IMAGE_ERRORS:
            return None  # a broken relationship: treat as no background
        return Fill(image=blob, image_ext=ext) if _readable(blob) else None
    return None


def _covers(shape, width: int, height: int) -> bool:
    if None in (shape.left, shape.top, shape.width, shape.height):
        return False
    return (shape.left <= width * 0.02 and shape.top <= height * 0.02
            and shape.left + shape.width >= width * 0.98
            and shape.top + shape.height >= height * 0.98)


def _own_fill(owner, colors: dict[str, str], width: int, height: int) -> Fill | None:
    """The background a slide, layout or master sets itself, or None when it sets none.

    That is its own fill, a background style (taken as its base color, or _PLAIN when
    that is the theme's light color), or a full-slide picture or box.
    """
    bg = owner._element.cSld.bg
    if bg is not None:
        ref = bg.find(qn("p:bgRef"))
        color = _color(ref, colors)
        if color:
            return _PLAIN if color == colors.get("lt1") else Fill(color=color)
        found = _fill(bg.find(qn("p:bgPr")), owner.part, colors)
        if found is not None:
            return found
    for shape in list(owner.shapes)[:3]:
        if not _covers(shape, width, height):
            continue
        if shape.shape_type == MSO_SHAPE_TYPE.PICTURE:
            picture = _picture(shape)
            if picture is not None:
                return Fill(image=picture[0], image_ext=picture[1])
        if shape.shape_type == MSO_SHAPE_TYPE.AUTO_SHAPE:
            found = _fill(shape._element.spPr, owner.part, colors)
            if found is not None and found.color:
                return found
    return None


def _key(fill: Fill | None):
    return None if fill is None else (fill.color or hash(fill.image))


def _common_background(fills: list[Fill | None]) -> Fill | None:
    """The most common background; the plain default (None) counts too."""
    if not fills:
        return None
    winner = Counter(_key(fill) for fill in fills).most_common(1)[0][0]
    return next(fill for fill in fills if _key(fill) == winner)


def _logo(slides, width: int, height: int) -> Logo | None:
    """A small picture repeated in the same place on at least half the slides."""
    if len(slides) < 2:
        return None
    counts: Counter = Counter()
    samples = {}
    for slide in slides:
        seen = set()
        for shape in slide.shapes:
            if shape.shape_type != MSO_SHAPE_TYPE.PICTURE or None in (shape.width, shape.height):
                continue
            picture = _picture(shape)
            if picture is None or shape.width * shape.height > 0.05 * width * height:
                continue
            key = (picture[2], round(shape.left / width, 2), round(shape.top / height, 2))
            if key not in seen:
                seen.add(key)
                counts[key] += 1
                samples.setdefault(key, (picture, shape))
    if not counts:
        return None
    key, count = counts.most_common(1)[0]
    if count < 2 or count * 2 < len(slides):
        return None
    picture, shape = samples[key]
    return Logo(picture[0], picture[1], shape.left / width, shape.top / height,
                shape.width / width, shape.height / height)


def _read_deck(path: str | Path) -> _Deck:
    prs = _open(path)
    width, height = prs.slide_width, prs.slide_height
    presentation = prs.part._element
    slides = list(prs.slides)
    themes: dict = {}  # master part name: (master, theme)
    used: Counter = Counter()
    title_runs: list[_Run] = []
    body_runs: list[_Run] = []
    fills, backgrounds = [], []
    for slide in slides:
        layout = slide.slide_layout
        master = layout.slide_master
        name = master.part.partname
        if name not in themes:
            themes[name] = (master, _theme(master))
        theme = themes[name][1]
        used[name] += 1
        colors = _colors(theme, _color_map(slide, layout, master))
        shapes = [(shape, _runs(shape, master, presentation, colors, theme.major, theme.minor))
                  for shape in _iter_shapes(slide.shapes)
                  if shape.has_text_frame and shape.text_frame.text.strip()]
        title = _title_shape(shapes, height)
        for shape, runs in shapes:
            (title_runs if shape is title else body_runs).extend(runs)
        own = _own_fill(slide, colors, width, height)
        fills.append(own)
        effective = (own or _own_fill(layout, colors, width, height)
                     or _own_fill(master, colors, width, height))
        backgrounds.append(None if effective == _PLAIN else effective)
    if used:
        master, theme = themes[used.most_common(1)[0][0]]
    else:
        master = prs.slide_master
        theme = _theme(master)
    colors = _colors(theme, _color_map(master))
    if not slides:
        own = _own_fill(master, colors, width, height)
        backgrounds = [None if own == _PLAIN else own]
    return _Deck(width, height, colors, theme, title_runs, body_runs, fills, backgrounds,
                 _logo(slides, width, height))


def _mostly_on_slide(runs: list[_Run]) -> bool:
    total = sum(run.weight for run in runs)
    return total > 0 and 2 * sum(run.weight for run in runs if run.on_slide) >= total


def look_is_on_slides(path: str | Path) -> bool:
    """True when the slides override their layouts.

    That is: at least half the slides set their own background, a logo repeats on the
    slides, or at least half the title or body text has a font or color that its
    layout does not give. A background the slides only inherit does not count.
    """
    deck = _read_deck(path)
    if not deck.fills:
        return False
    own = sum(1 for fill in deck.fills if fill is not None)
    return (own * 2 >= len(deck.fills) or deck.logo is not None
            or _mostly_on_slide(deck.title_runs) or _mostly_on_slide(deck.body_runs))


def capture_style(path: str | Path) -> DeckStyle:
    """Read size, theme colors, text styles, backgrounds and a repeated logo."""
    deck = _read_deck(path)
    text = deck.colors.get("tx1")
    backgrounds = deck.backgrounds
    return DeckStyle(deck.width, deck.height, deck.theme.scheme,
                     _dominant(deck.title_runs, deck.theme.major, text),
                     _dominant(deck.body_runs, deck.theme.minor, text),
                     backgrounds[0] if backgrounds else None,
                     _common_background(backgrounds[1:] or backgrounds), deck.logo)


def describe_capture(style: DeckStyle, skipped: tuple[str, ...] = ()) -> str:
    """One plain sentence naming what the new template took from the deck."""
    taken = ["colors"]
    if style.title.font or style.body.font:
        taken.append("fonts")
    if (style.background or style.title_background) and "background" not in skipped:
        taken.append("background")
    if style.logo and "logo" not in skipped:
        taken.append("logo")
    return f"Taken from your deck: {', '.join(taken)}. Its slide designs are not copied."
```

```python
# simplicitor/templates_engine/styled_template.py
"""Build a fillable template that carries a captured deck look.

The base is the app's bundled copy of python-pptx's default template (the
package's own copy is unreachable in the packaged app). Its layouts have
title and content placeholders, so the existing renderer can fill it.
"""
import io
from pathlib import Path

from lxml import etree
from PIL import Image
from pptx import Presentation
from pptx.dml.color import RGBColor
from pptx.opc.constants import RELATIONSHIP_TYPE as RT
from pptx.oxml import parse_xml
from pptx.oxml.ns import nsdecls, qn
from pptx.oxml.shapes.picture import CT_Picture

from templates_engine.deck_style import DeckStyle, Fill, Logo, TextStyle

BASE_TEMPLATE = Path(__file__).resolve().parent.parent / "templates" / "pptx_default.pptx"
_FILLS = ("a:noFill", "a:solidFill", "a:gradFill", "a:blipFill", "a:pattFill", "a:grpFill")
# Reading an image happens in memory: a failure skips that image. Saving the template
# is outside these guards, so a disk error still raises.
_IMAGE_ERRORS = (OSError, ValueError, Image.DecompressionBombError)


def _field(name: str, idx: int, kind: str, required: bool, **limit) -> dict:
    return {"name": name, "placeholder_idx": idx, "kind": kind, "required": required, **limit}


# Layout indices of the default template: 0 Title Slide, 1 Title and Content,
# 2 Section Header. Field limits match the built-in business_pitch template.
STYLED_SLIDE_TYPES = {
    "title": {"layout_index": 0, "fields": [
        _field("title", 0, "text", True, max_chars=60),
        _field("subtitle", 1, "text", False, max_chars=120)]},
    "agenda": {"layout_index": 1, "fields": [
        _field("heading", 0, "text", True, max_chars=40),
        _field("items", 1, "bullets", True, max_items=5)]},
    "content": {"layout_index": 1, "fields": [
        _field("heading", 0, "text", True, max_chars=60),
        _field("bullets", 1, "bullets", False, max_items=6)]},
    "closing": {"layout_index": 2, "fields": [
        _field("heading", 0, "text", True, max_chars=60),
        _field("statement", 1, "text", True, max_chars=160)]},
}


def styled_manifest(name: str, deck_name: str) -> dict:
    """The manifest for a template built by build_styled_template()."""
    return {"name": name, "type": "pptx", "template_file": "template.pptx",
            "description": f"Made from the look of {deck_name}.",
            "slide_types": STYLED_SLIDE_TYPES}


def _luminance(color: str) -> float:
    def channel(value: int) -> float:
        value /= 255
        return value / 12.92 if value <= 0.03928 else ((value + 0.055) / 1.055) ** 2.4
    red, green, blue = (int(color[i:i + 2], 16) for i in (0, 2, 4))
    return 0.2126 * channel(red) + 0.7152 * channel(green) + 0.0722 * channel(blue)


def _contrast(first: str, second: str) -> float:
    light, dark = sorted((_luminance(first), _luminance(second)), reverse=True)
    return (light + 0.05) / (dark + 0.05)


def _average(fill: Fill | None) -> str:
    """The background's color, or a picture's average color; white when unknown."""
    if fill is None:
        return "FFFFFF"
    if fill.color:
        return fill.color
    try:
        with Image.open(io.BytesIO(fill.image)) as image:
            red, green, blue = image.convert("RGB").resize((1, 1)).getpixel((0, 0))
    except _IMAGE_ERRORS:
        return "FFFFFF"
    return f"{red:02X}{green:02X}{blue:02X}"


def readable(color: str | None, background: str) -> str:
    """Keep the deck's text color when it reads at 3:1 or better; else black or white."""
    if color and _contrast(color, background) >= 3.0:
        return color
    black, white = _contrast("000000", background), _contrast("FFFFFF", background)
    return "000000" if black >= white else "FFFFFF"


def _set_color(rpr, color: str) -> None:
    for tag in _FILLS:
        for old in rpr.findall(qn(tag)):
            rpr.remove(old)
    solid = parse_xml(f'<a:solidFill {nsdecls("a")}><a:srgbClr val="{color}"/></a:solidFill>')
    line = rpr.find(qn("a:ln"))
    rpr.insert(list(rpr).index(line) + 1 if line is not None else 0, solid)


def _resize(prs, width: int, height: int) -> None:
    """Change the slide size and scale every master and layout shape that has its own position."""
    scale_x, scale_y = width / prs.slide_width, height / prs.slide_height
    prs.slide_width, prs.slide_height = width, height
    for owner in (prs.slide_master, *prs.slide_layouts):
        for shape in owner.shapes:
            if shape._element.spPr.find(qn("a:xfrm")) is None:
                continue  # inherits its position from the master
            shape.left, shape.top = round(shape.left * scale_x), round(shape.top * scale_y)
            shape.width, shape.height = round(shape.width * scale_x), round(shape.height * scale_y)


def _apply_theme(prs, style: DeckStyle) -> None:
    part = prs.slide_master.part.part_related_by(RT.THEME)
    root = etree.fromstring(part.blob)
    elements = root.find(qn("a:themeElements"))
    if style.color_scheme:
        elements.replace(elements.find(qn("a:clrScheme")), etree.fromstring(style.color_scheme))
    fonts = elements.find(qn("a:fontScheme"))
    for kind, font in (("a:majorFont", style.title.font), ("a:minorFont", style.body.font)):
        if font:
            fonts.find(f"{qn(kind)}/{qn('a:latin')}").set("typeface", font)
    part.blob = etree.tostring(root, xml_declaration=True, encoding="UTF-8", standalone=True)


def _apply_text(master, style_name: str, text: TextStyle, color: str, size_range: tuple) -> None:
    levels = master._element.find(f"{qn('p:txStyles')}/{qn('p:' + style_name)}")
    for level in levels:
        rpr = level.find(qn("a:defRPr"))
        if rpr is not None:
            _set_color(rpr, color)
    first = levels.find(qn("a:lvl1pPr")).find(qn("a:defRPr"))
    if text.size_pt:
        low, high = size_range
        first.set("sz", str(round(min(max(text.size_pt, low), high) * 100)))
    if text.bold is not None:
        first.set("b", "1" if text.bold else "0")


def _title_slide_colors(prs, title: str, body: str) -> None:
    """Override title-slide text colors where its background differs from the others."""
    for shape in prs.slide_layouts[0].placeholders:
        color = title if shape.placeholder_format.idx == 0 else body
        styles = shape._element.find(f"{qn('p:txBody')}/{qn('a:lstStyle')}")
        if styles is None:
            continue
        level = styles.find(qn("a:lvl1pPr"))
        if level is None:
            level = parse_xml(f'<a:lvl1pPr {nsdecls("a")}/>')
            default = styles.find(qn("a:defPPr"))
            styles.insert(list(styles).index(default) + 1 if default is not None else 0, level)
        rpr = level.find(qn("a:defRPr"))
        if rpr is None:
            rpr = parse_xml(f'<a:defRPr {nsdecls("a")}/>')
            extension = level.find(qn("a:extLst"))
            level.insert(list(level).index(extension) if extension is not None else len(level), rpr)
        _set_color(rpr, color)


def _set_background(owner, fill: Fill) -> None:
    if fill.color:
        background = owner.background.fill
        background.solid()
        background.fore_color.rgb = RGBColor.from_string(fill.color)
        return
    _, rid = owner.part.get_or_add_image_part(io.BytesIO(fill.image))
    properties = owner._element.cSld.get_or_add_bgPr()
    for tag in _FILLS:
        for old in properties.findall(qn(tag)):
            properties.remove(old)
    properties.insert(0, parse_xml(
        f'<a:blipFill {nsdecls("a", "r")} dpi="0" rotWithShape="1"><a:blip r:embed="{rid}"/>'
        '<a:srcRect/><a:stretch><a:fillRect/></a:stretch></a:blipFill>'))


def _add_logo(prs, logo: Logo) -> None:
    master = prs.slide_master
    _, rid = master.part.get_or_add_image_part(io.BytesIO(logo.image))
    width, height = prs.slide_width, prs.slide_height
    picture = CT_Picture.new_pic(master.shapes._next_shape_id, "Logo", "", rid,
                                 round(logo.left * width), round(logo.top * height),
                                 round(logo.width * width), round(logo.height * height))
    master.shapes._spTree.append(picture)


def _apply_pictures(prs, style: DeckStyle) -> list[str]:
    """Set backgrounds and the logo; return the parts whose images could not be read."""
    skipped: list[str] = []
    steps = [("background", style.background, prs.slide_master)]
    if style.title_background != style.background:
        steps.append(("title slide background", style.title_background, prs.slide_layouts[0]))
    for kind, fill, owner in steps:
        if fill is None:
            continue
        try:
            _set_background(owner, fill)
        except _IMAGE_ERRORS:
            skipped.append(kind)
    if style.logo is not None:
        try:
            _add_logo(prs, style.logo)
        except _IMAGE_ERRORS:
            skipped.append("logo")
    return skipped


def build_styled_template(style: DeckStyle, out_path: str | Path) -> list[str]:
    """Write a fillable template with *style*; return parts of the look that were skipped."""
    out_path = Path(out_path)
    prs = Presentation(str(BASE_TEMPLATE))
    _resize(prs, style.slide_width, style.slide_height)
    _apply_theme(prs, style)
    skipped = _apply_pictures(prs, style)
    # Choose text colors against the backgrounds that were really applied.
    content = _average(None if "background" in skipped else style.background)
    _apply_text(prs.slide_master, "titleStyle", style.title,
                readable(style.title.color, content), (24, 54))
    _apply_text(prs.slide_master, "bodyStyle", style.body,
                readable(style.body.color, content), (14, 32))
    if (style.title_background is not None and style.title_background != style.background
            and "title slide background" not in skipped):
        cover = _average(style.title_background)
        _title_slide_colors(prs, readable(style.title.color, cover),
                            readable(style.body.color, cover))
    temporary = out_path.with_name(out_path.name + ".tmp")
    try:
        prs.save(str(temporary))
        temporary.replace(out_path)
    finally:
        temporary.unlink(missing_ok=True)
    return skipped
```

```python
# scripts/sample_deck_styles.py
"""Render a sample deck for every .pptx in a folder, the way the app would import it.

Usage:
    .venv/Scripts/python.exe scripts/sample_deck_styles.py <decks folder> <output folder>

Each deck goes through templates_engine.config.prepare_template, the same choice the
app makes on import: its own layouts, or its captured look. One slide per slide type
is filled with representative text at the template's limits and rendered to
<name>-sample.pptx, with one line per deck in report.txt. No AI model is called.
The output folder must be outside the decks folder; nothing else is written.
"""
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT / "simplicitor"))

from PIL import Image  # noqa: E402

from templates_engine.config import MANIFEST_NAME, prepare_template  # noqa: E402
from templates_engine.manifest import Manifest, load_manifest  # noqa: E402
from templates_engine.render_pptx import render  # noqa: E402
from templates_engine.validation import validate_content  # noqa: E402

_WORDS = ("Revenue grew twelve percent against plan while support response time fell to "
          "four hours and two enterprise customers signed annual contracts with the team.")


def _text(limit: int | None) -> str:
    """Representative text: about 90% of the field limit, or one long sentence."""
    if limit is None:
        return _WORDS
    text = (_WORDS + " ") * (limit // len(_WORDS) + 1)
    cut = text[:max(1, int(limit * 0.9))]
    return cut.rsplit(" ", 1)[0] if " " in cut.strip() else cut.strip()


def sample_content(manifest: Manifest, picture: Path) -> dict:
    """One slide per slide type, every field filled near its limits."""
    slides = []
    for name, slide_type in manifest.slide_types.items():
        fields = {}
        for field in slide_type.fields:
            if field.kind == "text":
                fields[field.name] = _text(field.max_chars)
            elif field.kind == "bullets":
                fields[field.name] = [_text(70) for _ in range(field.max_items or 4)]
            else:
                fields[field.name] = str(picture)
        slides.append({"type": name, "fields": fields})
    return {"slides": slides}


def sample(deck: Path, out: Path, picture: Path) -> str:
    """Prepare one deck as the app would, render its sample, and return its report line."""
    folder = out / deck.stem
    folder.mkdir(parents=True, exist_ok=True)
    prepared = prepare_template(deck, folder, deck.stem)
    manifest = load_manifest(folder / MANIFEST_NAME)
    valid, content = validate_content(manifest, sample_content(manifest, picture))
    if not valid:
        raise ValueError("Sample content does not fit the template.")
    render(manifest, content, out / f"{deck.stem}-sample.pptx", folder)
    if not prepared["captured"]:
        return f"{deck.name}: own layouts kept, {len(manifest.slide_types)} slide types."
    skipped = f" Could not copy: {', '.join(prepared['skipped'])}." if prepared["skipped"] else ""
    return f"{deck.name}: look captured. {prepared['report']}{skipped}"


def main(decks: Path, out: Path) -> list[str]:
    decks, out = decks.resolve(), out.resolve()
    if decks == out or decks in out.parents or out in decks.parents:
        raise SystemExit("Choose an output folder outside the decks folder.")
    out.mkdir(parents=True, exist_ok=True)
    picture = out / "sample-picture.png"
    Image.new("RGB", (640, 480), (150, 150, 150)).save(picture)
    lines = []
    for deck in sorted(decks.glob("*.pptx")):
        try:
            lines.append(sample(deck, out, picture))
        except Exception as exc:  # report every deck, even one that fails
            lines.append(f"{deck.name}: FAILED ({type(exc).__name__})")
    (out / "report.txt").write_text("\n".join(lines) + "\n", encoding="utf-8")
    return lines


if __name__ == "__main__":
    if len(sys.argv) != 3:
        sys.exit(__doc__)
    for line in main(Path(sys.argv[1]), Path(sys.argv[2])):
        print(line)
```
